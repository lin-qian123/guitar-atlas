# Guitar Atlas third-party notices

Guitar Atlas is an independent multi-source catalog and local offline library.
It is not affiliated with, sponsored by, or endorsed by the websites below.
Source records retain their own identity and attribution, even when titles
look alike or local files contain identical bytes.

## IMSLP / Petrucci Music Library

[IMSLP](https://imslp.org/) supplies work and instrumentation-category records.
The catalog preserves original titles, musician attributions, native work IDs,
category names, and links to the corresponding work and category pages.

The project is not affiliated with Project Petrucci LLC or IMSLP mirror
operators. IMSLP page content and individual files have their own applicable
terms. Copyright status can differ by jurisdiction; the catalog's inclusion
rules do not constitute a copyright determination.

See IMSLP's [general disclaimer](https://imslp.org/wiki/IMSLP:General_disclaimer)
and [licensing policy](https://imslp.org/wiki/IMSLP:Free_content_licenses).

## ClassClef

[ClassClef](https://www.classclef.com/) supplies guitar repertoire records and
source-directory relationships. The catalog preserves available original titles,
musician attributions, source record IDs, and links to source pages. Source
classification is kept separate from IMSLP's exact instrumentation categories.

ClassClef availability or a free-download label does not establish a score's
copyright status or grant redistribution permission. Any attribution, edition,
arranger, copyright, and licensing information in the source page or file remains
applicable. Guitar Atlas does not claim ownership of ClassClef content or extend
its own license to source files.

## Publication boundary

The public site hosts no scores, MIDI, or Guitar Pro files and exposes no direct
file or download URLs. Verified files in a private local collection are not
included in the Git repository or GitHub Pages export. Every public record links
to a validated page on its source website.

New sources must be listed in the source registry and documented here before
their records are published. Their source terms remain separate from the
project's software and original documentation licenses.
