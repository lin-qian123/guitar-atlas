# 六弦漫行：视觉参考与设计取舍

调研日期：2026-10-04。目标是为吉他乐谱目录建立独立、精致的视觉语言，同时保留 48,449 条记录的检索、来源、版本信息及离线使用方式。

本轮直接浏览了以下 10 家官网，读取官网页面内容，并在独立研究标签页中检查实际渲染、DOM 和部分 `getComputedStyle` 声明。桌面观察视口为 1280 × 720；下列字体、字号、圆角、过渡时间来自所选元素的当次样本，并非网站全部断点或完整设计规范。动效时间是 CSS 声明，没有把未测试的悬停轨迹或滚动行为当成事实。部分网站的宣传弹窗、异步图片或视频未完整显示；观察仍以当时可见版式和控件为准。

## 本项目采用的设计方向

采用“琴谱出版物与馆藏索引”的语言：温暖象牙色纸底、深墨色文字、少量朱红；主体图像围绕古典吉他的结构、六弦与木工痕迹，独立制作，不复制上述品牌的图片、商标或完整构图。英文品牌保留 Guitar Atlas，中文主标题为六弦漫行。

- **字体与尺度。** 中文大标题及作品题名用系统宋体，拉丁展示字用可合法自托管的轻量衬线字体；按钮、筛选与说明用系统无衬线。桌面主标题与作品列表的尺度要明显分开，但长题名可自然换行。中英文基线、标点和行距应分别检查。
- **版式。** 首屏是一张不等宽图文扉页；目录从细分隔线开始。共同分类用章节编号与两至三栏索引，记录列表以题名、署名、来源和动作建立稳定阅读列。原来源分类仍可展开，移动端按相同阅读顺序收为一栏。
- **按钮与 R 角。** 搜索是长条组合控件；主要动作填深墨或朱红，次级动作用细线或文字。常用边界 0–3 px；圆形只服务独立小图标。所有控件有明确焦点状态、禁用状态、命中区域，精细边框不能依赖低对比度。
- **图像。** 一张原创主视觉足够建立辨识度。适合蚀刻、制琴手稿或出版物插图的细线，不采用泛化的“吉他 + 一摞书 + 装饰光效”场景。图像不承担未核验的谱面或来源信息；合理裁切，提供现代压缩格式与固有尺寸。
- **微动效。** 本项目建议控制在 160–260 ms：按钮色变、箭头小幅位移、目录条目的轻微底色响应、筛选展开。仅首屏元素可有一次短入场，禁用循环漂浮、自动轮播及重型滚动库；尊重 `prefers-reduced-motion`，键盘操作不能因动效等待。
- **密集数据。** 原始资料放在可展开的版本详情，中文题名与原题仍同时可访问。检索和来源筛选共用现有数据，保留匹配度和知名度排序；不因视觉改造改写记录身份、译名状态、文件链接或来源关系。
- **轻量。** 自托管少量字体与一张主视觉，不新增框架或远程字体请求。继续按需建立全文索引、分批呈现作品；默认目录页不预先铺开全部结果。公开与离线共用模板、样式与交互，离线不增加网络依赖。

## 细节验收重点

实际实现需要分别查看：默认目录、搜索结果、空结果、来源/共同分类筛选、详情展开、本地 PDF 链接、长中文与拉丁题名、加载/错误状态、键盘焦点与减少动效；再核对宽屏、常用桌面和手机的字级、空白、折行及边界。视觉截图能验证画面；目录身份、排序、链接和压缩数据应由相应程序检查，不能互相替代。

本研究是设计观察与实现取舍，未对这些网站的全部页面、移动端、无障碍、性能或版权许可作完整审核，也未将某个外站的美学偏好当成本项目的强制规范。
