# Instrument Serif

Regular and italic Latin display faces, self-hosted as WOFF subsets. Chinese
headings use the operating system's Songti/serif fonts; interface controls use
system sans-serif fonts. Both faces use `font-display: swap`.

Source: [Instrument's original project](https://github.com/Instrument/instrument-serif)
and the [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/instrumentserif).
Copyright 2022 The Instrument Serif Project Authors. SIL Open Font License 1.1,
included in [OFL.txt](OFL.txt).

The subset contains U+0020–U+024F plus the typographic dashes, quotation marks,
and outward arrow used in the page. Uncovered scripts retain system fallbacks.
Generated with fontTools; no remote font request is needed at runtime.
